## 已验证的业务能力

- 使用现有中转站启动 Codex 主控，使用已有原生 DSH ACP 适配器，不新建 Bridge 或调度服务。
- 两个 DSH Worker 在独立 Git Worktree 并发运行，实际测试退出码与日志归属明确。
- 独立 Codex 只读审查发现预置缺陷，登记一轮返工后重新测试和审查。
- 外部 Codex 接管后旧修订派工返回 409，现有结果保留；最终验收记录有人工补登记，不能据此宣称无人值守完成。
- 只读探针实际读取成功，原生写入被权限拒绝；loopback 可达单独作为可信本机限制。
- 安装版的项目登记、主控 CAS、需求去重、释放修订递增及重启持久化在真实 Electron 和随附后台上完成。

真实会话、提交和限制见 [原生联调](native-validation.md)；状态仍从原有持久事实推导。审查关联和交付收据没有另建调度器或任务状态机。

## 未完成的验收

1. 原生 GitHub PR Reviewer 尚未调用；私有合成测试 PR 已存在，但 PR 本身不能替代审查验收。
2. 完全无人值守闭环，以及启动中、执行中、结果同步中、等待审批时的全部故障点组合尚未覆盖。
3. 最新完整 CI 必须核对到精确提交；本机完整前后端套件仍存在失败。具体统计和已确认修复见安装验收报告。
4. 本机长路径检查被 Git 的 `Filename too long` 阻断，完整产品长路径链路未验收。未修改系统设置。
5. 非可信项目、恶意本机进程隔离、所有 loopback 阻断、多人和云执行不在首版承诺内。

因此本轮提供可安装、可检查的候选包与真实证据，并保留上述未验收项。继续真实模型验收需要新的明确额度；不会超出当前 20 次上限。
